How to help

Every subtitle file lives in one shared project on GitHub. You add a few subtitles at a time, and each film's page shows exactly where to continue, so nothing is done twice.

You need: a free GitHub account and a way to watch the film. No GitHub account? Email your subtitles instead.

In your browser

  1. Pick a film on the film list. Its page shows the next subtitle to translate and the original line, with a button to watch the film from that moment.
  2. Say which part you're taking with the button on the film's page, for example “I'm doing 5–20”. It opens the film's conversation on GitHub.
  3. Click “Edit on GitHub”. The subtitle file opens in GitHub's editor. The first time, GitHub offers to make your own copy of the project (a “fork”): say yes.
  4. Find your subtitle (⌘F or Ctrl+F, search for its number) and replace the English text with Georgian. Keep the number and the time line exactly as they are: 
    5
00:02:05,250 --> 00:02:06,300
გმადლობ.
  5. Stop whenever you like: five subtitles are a real help. Click Commit changes…, describe what you did (“Sintel: 5–20”), then Propose changes and Create pull request.
  6. Done. A maintainer checks your part and adds it. The film's progress moves on, and the next person starts after your last subtitle.

With Aegisub

Aegisub is a free subtitle editor for Windows, macOS and Linux. It plays the film beside the subtitles, so it's the best way to work for longer, and the tool to use for writing down a film's dialogue with exact times. Learning it is worth it if you want to get properly involved.

  1. Install Aegisub.
  2. From the film's page, download the latest subtitle file and the video.
  3. In Aegisub, open both: File → Open Subtitles, then Video → Open Video.
  4. To translate, use Subtitle → Translation Assistant: it shows each original line, and you type the translation. Start at the subtitle the film's page gives. To write down dialogue, add a line for each sentence and set its times on the audio waveform.
  5. Save with File → Export Subtitles… as SubRip (.srt), with the same file name, for example ka.srt.
  6. On the film's page, choose “Upload a file from Aegisub”, drop in your file, then Propose changes and Create pull request.

An upload can never undo anyone else's work. If someone added subtitles while you were working, the automatic check says so, and you add your part to the latest file instead.

Good subtitles

  • At most 2 lines per subtitle, and 42 characters per line.
  • Translate the meaning, in natural, everyday language. Short beats complete.
  • Georgian quotation marks „like this“. Foreign names as they sound: Thom → თომი.
  • In English subtitles of Georgian films, Georgian names in the national romanization, without apostrophes: ვაჟია → Vazhia.
  • Not sure about a line? Translate it as well as you can and say so in your pull request.

The subtitle checker finds lines that are too long or too fast, in your browser.

No GitHub account?

Email your subtitles to translation@foundation.ge, saying which film and which numbers. They'll be added for you, with your name if you'd like it.

Films that need permission

Most films are protected for 70 years after their last author dies, so they can only be subtitled with the rights holder's written permission. If you'd like to see one added, send the studio the permission letter.
