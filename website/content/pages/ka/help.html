როგორ დავეხმაროთ

სუბტიტრების ყველა ფაილი ერთ საერთო პროექტშია, GitHub-ზე. სუბტიტრებს ცოტ-ცოტას ამატებთ, თითოეული ფილმის გვერდზე კი ზუსტად ჩანს, საიდან უნდა გაგრძელდეს, ამიტომ არაფერი კეთდება ორჯერ.

დაგჭირდებათ: უფასო GitHub-ის ანგარიში და ფილმის ნახვის საშუალება. GitHub-ის ანგარიში არ გაქვთ? სუბტიტრები ელფოსტით გამოგზავნეთ.

ბრაუზერში

  1. აირჩიეთ ფილმი ფილმების სიაში. მის გვერდზე ჩანს შემდეგი სათარგმნი სუბტიტრი და ორიგინალი სტრიქონი, ასევე ღილაკი, რომლითაც ფილმს სწორედ იმ მომენტიდან ნახავთ.
  2. მიუთითეთ, რომელ ნაწილს იღებთ, ფილმის გვერდზე არსებული ღილაკით, მაგალითად: „ვთარგმნი 5–20-ს“. ის GitHub-ზე ფილმის განხილვას გახსნის.
  3. დააჭირეთ „რედაქტირება GitHub-ზე“-ს. სუბტიტრების ფაილი GitHub-ის რედაქტორში გაიხსნება. პირველად GitHub პროექტის საკუთარი ასლის („fork“) შექმნას შემოგთავაზებთ: დაეთანხმეთ.
  4. იპოვეთ თქვენი სუბტიტრი (⌘F ან Ctrl+F, მოძებნეთ მისი ნომერი) და ინგლისური ტექსტი ქართულით ჩაანაცვლეთ. ნომერი და დროის ხაზი ზუსტად ისე დატოვეთ, როგორც არის: 
    5
00:02:05,250 --> 00:02:06,300
გმადლობ.
  5. გაჩერდით, როცა გინდათ: ხუთი სუბტიტრიც დიდი დახმარებაა. დააჭირეთ Commit changes…-ს, აღწერეთ, რა გააკეთეთ („სინტელი: 5–20“), შემდეგ კი Propose changes-სა და Create pull request-ს.
  6. მზადაა. მოდერატორი თქვენს ნაწილს შეამოწმებს და დაამატებს. ფილმის პროგრესი წინ წაიწევს, შემდეგი ადამიანი კი თქვენი ბოლო სუბტიტრის შემდეგ დაიწყებს.

Aegisub-ით

Aegisub უფასო სუბტიტრების რედაქტორია Windows-ის, macOS-ისა და Linux-ისთვის. ის ფილმს სუბტიტრების გვერდით უშვებს, ამიტომ ხანგრძლივი მუშაობისთვის საუკეთესოა, ფილმის დიალოგების ზუსტი დროით ჩასაწერად კი — აუცილებელი. თუ პროექტში სერიოზულად ჩართვა გსურთ, მისი შესწავლა ღირს.

  1. დააინსტალირეთ Aegisub.
  2. ფილმის გვერდიდან ჩამოტვირთეთ სუბტიტრების ბოლო ვერსია და ვიდეო.
  3. Aegisub-ში გახსენით ორივე: File → Open Subtitles, შემდეგ Video → Open Video.
  4. სათარგმნად გამოიყენეთ Subtitle → Translation Assistant: ის ორიგინალის თითოეულ სტრიქონს გაჩვენებთ, თქვენ კი თარგმანს წერთ. დაიწყეთ იმ სუბტიტრიდან, რომელსაც ფილმის გვერდი მიუთითებს. დიალოგების ჩასაწერად თითოეული წინადადებისთვის დაამატეთ სტრიქონი და მისი დრო აუდიოს ტალღაზე დააყენეთ.
  5. შეინახეთ File → Export Subtitles…-ით, SubRip (.srt) ფორმატში, იმავე სახელით, მაგალითად ka.srt.
  6. ფილმის გვერდზე აირჩიეთ „Aegisub-ის ფაილის ატვირთვა“, ჩააგდეთ ფაილი, შემდეგ კი დააჭირეთ Propose changes-სა და Create pull request-ს.

ატვირთვა სხვის ნამუშევარს ვერასოდეს წაშლის. თუ თქვენი მუშაობისას ვინმემ სუბტიტრები დაამატა, ავტომატური შემოწმება ამას გეტყვით და თქვენს ნაწილს ბოლო ვერსიას დაამატებთ.

კარგი სუბტიტრები

  • ერთ სუბტიტრში მაქსიმუმ 2 სტრიქონი, სტრიქონში კი მაქსიმუმ 42 სიმბოლო.
  • თარგმნეთ აზრი, ბუნებრივი, ყოველდღიური ენით. მოკლე სჯობს სრულს.
  • ბრჭყალები „ასე“. უცხოური სახელები ისე, როგორც ჟღერს: Thom → თომი.
  • ქართული ფილმების ინგლისურ სუბტიტრებში ქართული სახელები — ლათინური ტრანსლიტერაციის ეროვნული სისტემით, აპოსტროფების გარეშე: ვაჟია → Vazhia.
  • სტრიქონში დარწმუნებული არ ხართ? თარგმნეთ, როგორც შეგიძლიათ, და pull request-ში მიუთითეთ.

სუბტიტრების შემმოწმებელი ზედმეტად გრძელ ან სწრაფ სტრიქონებს პოულობს, პირდაპირ ბრაუზერში.

GitHub-ის ანგარიში არ გაქვთ?

სუბტიტრები გამოგზავნეთ მისამართზე translation@foundation.ge და მიუთითეთ ფილმი და ნომრები. მათ თქვენ მაგივრად დაამატებენ, თუ გსურთ — თქვენი სახელით.

ფილმები, რომლებსაც ნებართვა სჭირდება

ფილმების უმეტესობა მისი ბოლო ავტორის გარდაცვალებიდან 70 წლის განმავლობაში დაცულია, ამიტომ მათი თარგმნა მხოლოდ უფლებების მფლობელის წერილობითი ნებართვით შეიძლება. თუ გსურთ, რომ ასეთი ფილმი დაემატოს, სტუდიას ნებართვის თხოვნის წერილი გაუგზავნეთ.
